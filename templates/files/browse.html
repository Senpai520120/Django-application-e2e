{% if table_formats %}
Table files ({% for ext in table_formats %}{{ ext }}{% if not forloop.last %}, {% endif %}{% endfor %}) are grouped by a column within a minute after upload. How to prepare one
  • The first row holds the column names: short, in Latin letters, no spaces (category, not Product category).
  • Rows are grouped by the column named in Group by column. Left empty, it is the first text column, so put there a value that repeats: a category, a city, a status.
  • Aggregations adds math per group, comma-separated: {% for op in aggregation_ops %}{{ op }}(column){% if not forloop.last %}, {% endif %}{% endfor %}. count works on any column, the others on numbers only. Example: sum(clicks), avg(impressions).
  • To group a file by another column or with other math, delete it and upload it again.
  • Every row has as many values as there are columns.
  • CSV: comma between values, UTF-8 encoding, a value with a comma inside goes in quotes ("Lego, big set"), decimals with a dot (12.5). In Excel choose Save as → CSV UTF-8.
  • Excel (.xlsx): only the first sheet is read, the table starts in cell A1.
  • JSON: a list of records, [{"category": "books", "amount": 12}, …].
  • Other files are stored as they are, without processing.
